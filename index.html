Pengingat

Data Pasien

Antrian shift ini disimpan di HP dan ikut sinkron ke server klinik secara real-time, lalu baru masuk ke data pasien serta entry saat End Shift. Ketuk status untuk mengubahnya, ketuk kartu untuk melengkapi data.

Laporan

Laporan dibuat sebagai surat. Di pratinjau tersedia Cetak, PDF, dan Foto. Sebelum dicetak/disimpan, Anda diminta tanda tangan di kotak konfirmasi. Nama file tetap (Laporan-Bulanan dan Laporan-Status-Clinic), jadi ekspor ulang menggantikan file lama di folder laporan/.

Apps Script (export & cetak ke Drive)

Data harian sudah real-time lewat server klinik (panel di atas). Apps Script hanya dipakai untuk menaruh hasil export Excel ke folder storage serta hasil cetak/PDF ke folder cetak dan laporan di Drive. Link folder dan token diatur di Script Properties Apps Script.

Ekspor Excel ke folder storage

Untuk melihat atau mengolah data lengkap di Excel. File dibuat di HP lalu dikirim sekali jalan ke folder storage di Drive. Nama tetap (Data Pasien.xlsx, Entry Harian.xlsx, Kilaw_note.xlsx), jadi ekspor ulang menggantikan yang lama (yang lama masuk tong sampah Drive). Otomatis juga dijalankan saat End Shift. Tidak dipakai untuk sinkron harian.

Impor file Excel dari HP

Untuk memasukkan data awal dari file lama. Isi di HP ini akan ditimpa isi file.

Input Data Pasien

No.RM tertinggi saat ini: -

Format satu baris per pasien:

NoFile.Nama.Umur.Alamat.NoTelp.Gender(l/p)

Tekan Enter untuk mengisi saran No.RM berikutnya, lalu setiap Enter menambah titik ke kolom selanjutnya. Setelah data lengkap, Enter pindah ke baris baru. Gunakan Shift+Enter untuk baris baru biasa.

Input Entry Harian

Format satu baris per kunjungan (tanpa tanggal — dipakai dari tanggal di atas):

NoFile.Nama.Umur.Alamat.Diagnosis/Gigi.Tindakan.Biaya.Paraf

Biaya boleh diberi metode bayar: 150000(qr). Tanpa keterangan dianggap cash. Kosongkan paraf atau isi - jika ditangani owner sendiri (tidak perlu paraf).

Ketik No.RM lalu Enter — nama, umur, dan alamat terisi otomatis dari data pasien. Enter di tiap kolom menambah titik; di kolom paraf, Enter kosong berarti Owner dan pindah baris.
